# 🚀 CyberCode Hackathon 2025 - Futuristic Website

A modern, animated hackathon website built with **MERN stack** (MongoDB, Express.js, React, Node.js) and **Vite** for lightning-fast development.

![CyberCode Logo](https://via.placeholder.com/150x50/00D4FF/000000?text=CYBERCODE)

## ✨ Features

### 🎨 **Futuristic Design**
- **Color Scheme**: Electric Blue (#00D4FF), Neon Purple (#8B5CF6), Cyber Green (#00FF88)
- **Glassmorphism**: Modern glass-like components with backdrop blur effects
- **Neon Glows**: Animated neon effects and particle systems
- **Responsive**: Mobile-first design that works on all devices

### 🧩 **Website Sections**
- **Modern Header**: Glassmorphism navigation with smooth animations
- **Hero Section**: 3D animated background with countdown timer
- **About Section**: Feature showcase with animated cards
- **Timeline**: Interactive vertical timeline with progress indicators
- **Events**: Filterable event cards with registration status
- **Gallery**: 3D carousel with sponsor showcase
- **Footer**: Comprehensive links and newsletter signup
- **Student Dashboard**: Complete profile and project management system

### 🛠 **Technology Stack**

#### Frontend
- **React 18** + **TypeScript** for type safety
- **Vite** for fast development and building
- **Tailwind CSS v3** for styling
- **Framer Motion** for smooth animations
- **React Router** for navigation
- **Lucide React** for icons

#### Backend (Coming Soon)
- **Node.js** + **Express.js**
- **MongoDB** with **Mongoose**
- **JWT** authentication
- **RESTful APIs**

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd hackathon
```

2. **Install frontend dependencies**
```bash
cd client
npm install
```

3. **Start the development server**
```bash
npm run dev
```

4. **Open your browser**
Navigate to `http://localhost:5173` to see the futuristic website in action!
